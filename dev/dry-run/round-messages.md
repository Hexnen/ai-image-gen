used in the rounds; source: round-5 request history `dry5-*` and round 7 `dry7-*`). Drawer values are set by the stand-in
GM before the message (`setOptions`), never by the model. The round-6 multi-hero conversation keeps its own list in
`round5-6-cases.md` (Round 6).
