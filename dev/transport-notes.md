# Transport Anthropic kreatora (T1): notatki i otwarte decyzje

Data: 2026-11-17. Kod: `scripts/anthropic/` (`index.mjs`, `request.mjs`, `sse.mjs`, `transport.mjs`, `pricing.mjs`). Testy: `node dev/test-transport.mjs` (27 testów, stub fetch z realistycznym SSE, bez sieci i bez prawdziwego klucza).

## Co jest

- `buildMessagesRequest(opts)`: ciało i nagłówki żądania; układ cache wg spec 9.1: `tools` posortowane po nazwie ze stałą kolejnością kluczy, `system` = [reguły harnessu, digest reguł, indeks katalogu] z JEDNYM jawnym znacznikiem `{ephemeral, ttl:"1h"}` na ostatnim bloku, top-level `cache_control: {ephemeral}` (automatyczny ogon 5 min). Blok arkusza (`<sheet…>`, `<sheet_update>`, `<sheet_unchanged/>`) w `system` jest odrzucany; arkusz idzie tylko w `userTurn({ sheet, text })` jako PIERWSZY blok wiadomości GM-a.
- Domyślnie `claude-sonnet-5-5`, `output_config.effort: "medium"`, `max_tokens` 32000, `stream: true`, `thinking` nie wysyłane (adaptive domyślnie), `tool_choice` auto przez pominięcie (any/tool rzuca błąd lokalnie: 400 na tych modelach), `fallbacks: "default"` + beta `server-side-fallback-2026-07-01` dla modeli z `FALLBACK_MODELS`.
- Klucz: tylko w `x-api-key`; `req.headers` jest niewyliczalne (JSON.stringify(req) go nie pokazuje), `req.redactedHeaders()` do logów. Każdy tekst błędu / zdarzenia przechodzi przez `redactSecrets(text, [key], redact)`; `redact` = opcjonalna funkcja modułu (`scripts/redact.mjs`), którą wołający podaje w `streamMessage(req, { redact })` (sam `redact.mjs` nie jest czysty: importuje `settings.mjs` z globalami Foundry).
- `streamMessage(req, o)`: fetch + SSE (`SSEParser` + `MessageAccumulator`), zdarzenia dla UI przez `onEvent` (attempt, message_start, block_start, text, thinking, tool_input, tool_use, fallback, block_stop, usage, message_stop, retry), przerwanie (`signal`, Stop GM-a), limit całego żądania (10 min), wykrywanie zawieszenia (90 s bez bajtów), ponowienia, mapowanie błędów na `TransportError.kind`. Wynik: `message` (dokładnie jak przyszło), `historyContent` (do dopisania jako wiadomość asystenta), `stop` (done / tool_use / max_tokens / refusal / pause_turn / context), `toolUses` (z `inputError` i `truncated`), `usage` (znormalizowane liczniki), `cost.usd`, `fallback`, `attempts`, `requestId`, `durationMs`.
- `toolResultsTurn(results)`: wszystkie wyniki narzędzi w JEDNEJ wiadomości użytkownika (równoległe wywołania).
- `buildPrewarmRequest` + `sendMessage`: pre-warm `max_tokens: 0` bez streamu, bez znacznika ogona.
- `prefixBytes` / `prefixFingerprint`: bajty prefiksu (model, tools, system, thinking, effort) do testów stabilności cache (T2: `test-build-cache-stability`).
- `pricing.mjs`: tabela cen (stan skilla claude-api z 2026-11-03), `costOfUsage` (z `usage.iterations` przy fallbacku: każda próba po cenie swojego modelu), `normalizeUsage`, `addUsage`, `cacheHitRatio`, `estimateMaxCost` (górna granica do rezerwacji limitów), `estimateTokens`.

## Zweryfikowane / niezweryfikowane

- Zweryfikowane (testy węzła z podstawionym fetch): kształt żądania i nagłówków, układ cache, stabilność bajtów prefiksu między turami / aktorami / kolejnością narzędzi, parser SSE (podział w dowolnym miejscu, CRLF, CR, komentarze, wieloliniowe `data`), tekst + thinking z podpisem, tool_use z częściowym JSON i równoległe wywołania, odmowa, pause_turn, fallback z `usage.iterations`, błędy HTTP i `event: error` w trakcie, 429/529 z ponowieniem, limit ponowień, `x-should-retry`, zerwane połączenie, strumień bez `message_stop`, przerwanie przez GM-a (w trakcie, przed startem, w czasie backoffu), zawieszenie, limit całego żądania, fetch ignorujący sygnał, brak klucza, odpowiedź JSON (pre-warm), klucz nigdy w wynikach / zdarzeniach / błędach (także gdy serwer lub TypeError fetch go cytuje), koszt.
- NIE zweryfikowane: prawdziwe CORS i SSE z przeglądarki do api.anthropic.com z nagłówkiem direct-browser-access (wymaga prawdziwego klucza i zgody właściciela na wydatek), realne nazwy nagłówków `request-id` / `x-should-retry` w odpowiedziach, czy `usage.iterations` ma pole `model`, czy nieudane strumieniowane próby są rozliczane, aktualność cen. Brak integracji z `limits.mjs` / `call-log.mjs` (to T2).
